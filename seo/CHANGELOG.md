# Changelog — SEO

## 0.1.0 — 2026-11-26

Первая версия плагина.

### Добавлено

- **Мета-теги на сайте**: `title`, `description`, `robots`, `canonical`,
  Open Graph, Twitter Card и JSON-LD (`WebSite`, `BreadcrumbList`, `Article`).
  Теги вставляются в готовый HTML, тема ничего менять не должна; для тем,
  которым нужен контроль, есть `{{ seo_meta() }}`.
- **SEO-поля для любой сущности** в отдельной таблице `plugin_seo_meta`
  (страницы, записи таблиц, разделы): схема ядра не меняется, миграция не нужна.
- **Советник**: оценка 0–100 по чек-листу из 20+ пунктов (заголовок, описание,
  объём, H1, ключевая фраза и её плотность, alt, внутренние ссылки, адрес,
  картинка для соцсетей, noindex, канон). Анализ офлайновый — без сети и токенов.
- **Карта сайта** `/sitemap.xml` из страниц, разделов и записей; `noindex`-страницы
  и адреса с редиректом в карту не попадают. Кэш на час, кнопка пересборки.
- **robots.txt** в режиме «авто»: отдаётся только когда своей страницы robots.txt
  в навигации нет.
- **301-редиректы** с счётчиком срабатываний и **журнал 404** с подсказкой
  ближайшего существующего адреса.
- **Генерация заголовка и описания** нейросетью через ключ DeepSeek из настроек CMS.
- Пункт меню с числом страниц, у которых оценка ниже 55.
