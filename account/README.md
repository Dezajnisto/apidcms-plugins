# Account — Личный кабинет

Плагин добавляет регистрацию, авторизацию и профиль пользователя на ваш сайт.

## Возможности

- **Регистрация:** email, имя, телефон, пароль (bcrypt)
- **Вход:** email + пароль, Remember-me (cookie 30 дней)
- **Восстановление доступа:** magic-link на email (одноразовый токен)
- **Смена пароля:** для авторизованных пользователей
- **Профиль:** просмотр и редактирование имени, телефона
- **Twig-функции:** `is_logged_in()`, `current_user()`

## Маршруты

| Путь | Действие |
|------|----------|
| `/register` | Регистрация |
| `/login` | Вход |
| `/account/forgot` | Восстановление доступа |
| `/account/reset?token=***` | Вход по magic-link |
| `/profile` | Профиль |
| `/account/change-password` | Смена пароля |
| `/logout` | Выход |

## Настройки

- `require_email_confirm` — требовать подтверждение email (в разработке)
- `default_role` — роль по умолчанию для новых пользователей
- `reset_token_ttl` — срок действия magic-link (1ч / 24ч / 7д)

## Таблицы

- `users` — пользователи
- `user_tokens` — токены (remember-me, password-reset)

## Требования

- apidcms >= 1.0.0
- Настроенная почта (`email_driver`, `email_from_*`) для magic-link

## Безопасность

- Пароли хешируются bcrypt
- Токены: 64 символа (random_bytes), одноразовые
- Rate-limit: один активный токен восстановления на email
- Универсальные сообщения (не раскрывают существование email)
