# NPD Plugin — Changelog

## 1.0.0 — 2026-11-25

### New

- **Автоматические чеки НПД.** После оплаты плагин регистрирует доход в
  «Мой налог» (`POST /api/v1/income`) и сохраняет ссылку на чек.
- **Очередь вместо «сразу в вебхуке»:** платёж попадает в таблицу
  `plugin_npd_receipts`, пробитие идёт после ответа ЮKassa. Сбой ФНС не теряет
  чек — он остаётся в журнале с текстом ошибки.
- **Вход по SMS** (ИНН + код): пароль ЛК физлица не спрашивается и не хранится.
  Токены лежат в базе зашифрованными, ключ — в `config/npd.php`.
- **Доставка чека:** страница `/receipts` в личном кабинете сайта, письмо
  (галочкой в настройках), ссылка в ответе API для ботов.
- **`POST /npd/income`** с HMAC-подписью — для источников дохода мимо
  `payments.*` хуков (движок бота «Дари!», наличные, ручная продажа).
- **`GET /npd/tick?key=…`** для cron: добирает очередь и повторяет неудачи.
- **Админка `/admin/npd`:** состояние подключения, вход по SMS, проверка связи,
  журнал со статусами и ошибками, кнопки «пробить» и «аннулировать».
- **Пробный режим** (`dry_run`, по умолчанию включён): платежи видны в журнале,
  в ФНС ничего не уходит — чтобы настраивать без риска.
- Тестовый магазин ЮKassa определяется по ключу `test_` — тестовые платежи
  в ФНС не уходят.

### Notes

- **Способ расчёта: `CASH` по умолчанию, `WIRE` — только перевод по счёту.**
  ФНС принимает ровно два значения; `ACCOUNT` отклоняется с
  `Cannot deserialize value of type IncomePaymentType ... not one of the values
  accepted for Enum class: [CASH, WIRE]`.
  По 422-ФЗ оплата картой приравнена к наличным (чек в момент расчёта), а
  «иные формы безналичных расчётов» со сроком до 9-го числа — это платёжное
  поручение. Поэтому карта на сайте = `CASH`, `WIRE` — для оплаты по счёту.
- **Аннулирование чека: endpoint `/api/v1/cancel`, а не `/income/cancel`.**
  Второй отдаёт 404 «Неверный формат запроса», что выглядит как ошибка
  авторизации. Кроме того, обязателен `requestTime`, а причина отмены —
  фиксированный список: `MISTAKE`, `REFUND`, `SERVICE_ERROR`.
- API `lknpd.nalog.ru` неофициальный: весь доступ собран в `src/Nalog.php`,
  чтобы правка при смене полей была в одном файле.
- Возвраты: аннулирование чека кнопкой в журнале. Автоматическая отмена по
  `refund.succeeded` — следующий этап (нужно событие в плагине `yookassa`).
