# apidcms-plugins

Официальные плагины для [apidcms](https://github.com/Dezajnisto/apidcms) — лёгкой CMS с ИИ-ассистентом.

## Доступные плагины

| Плагин | Версия | Описание |
|--------|--------|----------|
| 👤 [Account](account/) | 1.0.0 | Личный кабинет: регистрация, авторизация, профиль |
| 🛒 [Cart](cart/) | 1.0.0 | Корзина товаров с AJAX и чекаутом |
| ⭐ [Subscription](subscription/) | 1.4.0 | Подписки, тарифы, доступ к контенту (зависит от Account) |
| ❤️ [Favorites](favorites/) | 1.0.0 | Избранное: сердечки, панель в профиле, toggle API (зависит от Account) |
| 💳 [YooKassa](yookassa/) | 1.2.0 | Платёжный шлюз YooKassa для приёма платежей |

## Установка

### Через админку
1. Скачай ZIP нужного плагина из [Releases](https://github.com/Dezajnisto/apidcms-plugins/releases)
2. В админке: Плагины → Загрузить ZIP
3. Активируй в один клик

### Вручную
```bash
unzip plugin-name-1.0.0.zip -d /путь/к/проекту/plugins/
```

## Разработка

Хочешь добавить свой плагин или улучшить существующий?

1. Форкни репозиторий
2. Добавь папку с плагином (см. [структуру ниже](#структура-плагина))
3. Добавь запись в `plugins.json`
4. Открой Pull Request

### Структура плагина

```
my-plugin/
├── plugin.json          # метаданные, настройки, зависимости
├── init.php             # точка входа
├── controllers/         # PHP-контроллеры (опционально)
├── migrations/          # SQL-миграции (опционально)
├── models/              # модели данных (опционально)
└── views/               # Twig-шаблоны (опционально)
```

Подробнее: [Руководство разработчика плагинов](https://apidcms.dezajno.ru/docs/plugin-dev-guide)
