# SEO — мета-теги, sitemap и SEO-советник

Плагин даёт сайту на apidcms всё, что поисковики просят в обязательном порядке,
и показывает, что на каждой странице не так.

Установка не трогает ядро: SEO-поля живут в отдельной таблице, а тема получает
теги уже в готовом HTML.

## Что делает

**На сайте**

- `title`, `description`, `robots`, `canonical` — для каждой страницы, записи
  и раздела. Значение из SEO-полей перекрывает контент; пустое поле оставляет
  то, что написал автор.
- Open Graph и Twitter Card — как ссылка выглядит в мессенджерах, Telegram и соцсетях.
- JSON-LD: `WebSite` для всего сайта, `BreadcrumbList` для вложенных адресов,
  `Article` для записей таблиц.
- `hreflang` при включённых языках сайта (Настройки → Языки).
- `/sitemap.xml` — карта сайта из страниц, разделов и записей, без `noindex`.
- `/robots.txt` в режиме «авто» — только если своей страницы robots.txt в навигации нет.
- 301-редиректы для переехавших адресов и журнал 404: что ищут и не находят.

**В админке**

- Раздел **SEO**: средняя оценка сайта, список страниц с оценкой 0–100 и
  фильтрами «проблемы / не проверены / хорошо», проверка всего сайта в один клик.
- Редактор страницы: поля, чек-лист из 20+ пунктов, превью сниппета в выдаче,
  счётчики длины, кнопка «Сгенерировать заголовок и описание» (нейросеть).
- Журнал 404 с подсказкой «куда перенаправить».
- Редиректы: добавить, посмотреть счётчик срабатываний, удалить.

## Что проверяет советник

| Группа | Пункты |
|---|---|
| Заголовок | есть, 30–65 символов, не повторяется на сайте |
| Описание | есть, 70–170 символов, не повторяется |
| Текст | объём от 300 слов, ровно один H1, есть подзаголовки H2–H4 |
| Ключевая фраза | в заголовке, описании, тексте, адресе; плотность 0,4–4,5% |
| Картинки и ссылки | alt у картинок, внутренние ссылки |
| Адрес | латиница, дефисы, не глубже трёх уровней |
| Соцсети и индексация | картинка для соцсетей, noindex, канонический адрес |

Оценка — взвешенная сумма: критичное (заголовок, объём, H1, фраза в тексте)
весит больше, косметика — меньше. Проверки, которые не применимы к странице
(например, объём текста у страницы-формы), оценку не портят.

Проверка офлайновая: анализатор читает базу, не ходит в интернет и не тратит
токены. Нейросеть нужна только кнопке «Сгенерировать».

## Настройки

Админка → Плагины → SEO. Ключи и значения хранятся в `plugin_settings`.

| Настройка | Смысл |
|---|---|
| Выводить мета-теги | главный выключатель вывода в `<head>` |
| Open Graph и Twitter | блок соцсетей |
| JSON-LD | микроразметка |
| Картинка для соцсетей по умолчанию | когда у страницы нет своей |
| Шаблон заголовка | `{title} — Мой сайт`; пусто — заголовок как есть |
| Отдавать sitemap.xml | карта сайта |
| robots.txt | авто / всегда / не трогать |
| noindex для 404 | страница ошибки не попадает в индекс |
| Кнопка «Сгенерировать» | доступ к нейросети через ключ DeepSeek из настроек CMS |

## Если тема выводит теги сама

Плагин правит готовый HTML: заменяет `title`, убирает дубли
`description`/`robots`/`canonical`/`og:*` и вставляет свой блок перед `</head>`.
Если тема должна управлять выводом сама, вызовите в её шаблоне:

```twig
<head>
    {{ seo_meta() }}
</head>
```

Тогда плагин второй раз ничего не вставит.

## Оформление

Плагин рисует себя **своим CSS** (`views/_styles.twig`, классы с префиксом `.seo-`)
и **инлайн-SVG** (`views/_icons.twig`), не полагаясь на классы Tailwind из
`admin.css` ядра. Это не капризы: `admin.css` — собранный (purged) Tailwind, в
нём только то, что использует ядро, а Font Awesome с cdnjs в этой сборке не
загружает шрифт. Плагин, написанный на «свободных» классах Tailwind, выглядит
сломанным, хотя HTML корректен.

Если добавляете разметку — используйте классы `.seo-*` и `icons.icon('name')`.

## Проверка

Логика анализатора проверяется без сайта и базы — из консоли:

```bash
php plugins/seo/tools/selftest.php
```

18 проверок на оценку, чек-лист, дубли и адреса. Код возврата 1 — есть провал.
После правки чек-листа прогоняйте обязательно: оценка меняется молча.

## Совместимость

- Ядро 2.8.0 и новее (нужны хуки `front.output`, `front.router.before`, `admin.routes`).
- Внешних зависимостей нет: только PHP 8.1+, SQLite и штатные классы CMS.
- Таблицы: `plugin_seo_meta`, `plugin_seo_redirect`, `plugin_seo_404`.
- Свою страницу `sitemap.xml` или `robots.txt` в навигации плагин не перекрывает.

## Что плагин не делает

Он не обещает позиций в выдаче и не заменяет работу с текстом: он показывает
проблемы и помогает их закрыть. Внешняя ссылочная масса, скорость отдачи
сервера и поведенческие факторы — вне его ответственности.
